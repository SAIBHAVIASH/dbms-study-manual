DBMS LAB STUDY HUB

WHAT IS INCLUDED
- index.html: the DBMS Lab Study Hub website
- pdfs/: Week 1 to Week 8 lab PDFs and two viva/syntax reference PDFs
- The website works offline when this folder stays together

OPEN OFFLINE
1. Extract DBMS_Lab_Study_Hub.zip.
2. Keep index.html beside the pdfs folder.
3. Open index.html in Chrome, Edge, or another browser.
4. Use the search box, week links, Open PDF, or Download PDF.

PUBLISH WITH GITHUB PAGES
1. Create a GitHub repository named dbms-lab-study-hub.
   With GitHub Free, use a public repository for GitHub Pages.
2. Upload the contents of this folder to the repository root:
   index.html, README.txt, and the complete pdfs folder.
3. Open the repository's Settings, then Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and /(root), then choose Save.
6. After GitHub finishes publishing, open the address shown in Settings > Pages.
   The usual address is https://YOUR-USERNAME.github.io/dbms-lab-study-hub/

PUBLIC SHARING
GitHub Pages content is public on the internet. Anyone with the site address can
open or download the PDFs. Check that you are allowed to share these files before
publishing them.

COLLEGE COMPUTER BACKUP
No hosted website can be guaranteed to work on every college network. If the
online site is blocked or internet is unavailable, keep the ZIP on a USB drive,
extract it on the college computer, and open index.html. If the computer blocks
local HTML files, ask the college IT staff for an approved way to open the folder.

The site uses local HTML, CSS, JavaScript, and PDFs only. It does not need an
account, installation, external scripts, web fonts, or an internet connection
after the folder has been downloaded.
